# Blue Orbit Tasks

Create a modern, futuristic task management app with a sleek tech-inspired UI. Use a dark navy background, electric blue accents, subtle neon glows, clean typography, and glassmorphism cards. Include a dashboard with task lists, categories, progress tracking, task creation, completion checkboxes, and a dark/light mode toggle. Make the layout minimal, responsive, and easy to navigate, with smooth animations and a premium SaaS aesthetic inspired by Linear and modern AI productivity tools.
